# Небесный рубеж / Sky Strike

Самостоятельный офлайн-прототип авиационной аркады для Android.
Игра разрабатывается в отдельной ветке `sky-strike-prototype`.

План версии 0.1: трёхмерный самолёт с силуэтом Су-57, три района 32 × 32 км,
наземные базы, зенитные комплексы, истребители и вертолёты, игровой радар,
захват цели, ракеты, пушка, ловушки и встроенные русские голосовые предупреждения.

Лётная модель и работа вооружения условные, предназначены для аркадной игры.
Это не тренажёр и не воспроизведение характеристик реального самолёта.

Исходники моделей и ландшафтов создаются процедурно. Three.js распространяется
по MIT; голосовые записи генерируются eSpeak NG и включаются в APK.
