# Небесный рубеж / Sky Strike 0.1.0

Играбельный 3D-прототип офлайн-авиационной аркады для Android.
Исходники находятся в ветке `sky-strike-prototype`; приложение Bless Offban
продолжает жить в `main`.

## Что работает

- Самолёт с условным силуэтом Су-57, управление креном и высотой, тяга и форсаж.
- Три района по 32 × 32 км: горная долина, архипелаг и пустынный каньон.
- По три базы на карте: командные пункты, радары, зенитные установки и ЗРК.
- Противник поднимает истребители и вертолёты; наземная оборона атакует игрока.
- Игровая РЛС с режимами «земля» / «воздух» и экранированием рельефом.
- Захват цели, управляемые ракеты, пушка, ловушки, повреждения и пополнение запасов.
- 14 встроенных русских голосовых сообщений, звук двигателя и боевые эффекты.
- Сенсорное управление, два вида камеры, две сложности и три уровня графики.
- Пауза и сохранение текущего вылета на устройстве, продолжение после перезапуска.

Модели и местность процедурные, графика упрощённая. Лётная модель, РЛС,
вооружение и противники условные и рассчитаны на аркаду. Характеристики
реального Су-57 не воспроизводятся. Вылет начинается в воздухе; детальная
кабина, взлёт и посадка, дополнительные самолёты пока не реализованы.

## Как играть

Выберите район и нажмите «Начать вылет». Левый джойстик управляет курсом и
высотой: вверх — набор высоты, вниз — снижение; отпускание выравнивает самолёт.
Переключайте цели кнопкой «Цель», режимы РЛС — кнопкой «Режим».
Удерживайте цель перед самолётом до захвата, затем нажмите «Пуск».
Для пушки удерживайте её кнопку. При ракетной атаке используйте ловушки.

Задача — уничтожить три командных пункта и вернуться к зелёному кольцу снабжения.
Пролёт через кольцо с умеренной скоростью ремонтирует самолёт и пополняет боезапас.
Кнопка паузы сохраняет вылет. В меню появляется кнопка «Продолжить».
При низкой частоте кадров выберите графику «Экономная».

Клавиатура для проверки на компьютере: WASD / стрелки — полёт, пробел — пушка,
Enter — ракета, F — ловушки, Tab — цель, R — режим, Shift — форсаж, C — камера,
Esc — пауза. Наклоном телефона управление пока не предусмотрено.

## Android и офлайн-режим

Application ID: `ru.bless.skystrike`, версия `0.1.0`, `versionCode = 1`.
Минимальная версия Android — 8.0 (API 26). Нужны OpenGL ES 3.0 и Android System
WebView с поддержкой WebGL 2 и современного JavaScript. Работа проверена
на эмуляторе Android 16; производительность на физических телефонах ещё
требует проверки.

Код, карты, модели и голосовые записи включены в APK. Разрешение `INTERNET`
отсутствует. WebView загружает только локальные ресурсы через WebViewAssetLoader,
внешние адреса блокируются. Аккаунт, сервер и системный онлайн-синтез речи
для игры не нужны. Интернет необходим только при сборке исходников.

## Сборка

Инструменты: Node.js 22, Python 3, eSpeak NG, JDK 17, Gradle 8.11.1,
Android SDK Platform 36. Версии npm-зависимостей закреплены в lock-файле.

```sh
npm ci
npm test
python3 tools/make_audio.py
npm run build
gradle --no-daemon :app:assembleRelease :app:lintRelease
```

Результат: `app/build/outputs/apk/release/app-release-unsigned.apk`.
Перед установкой release APK нужно подписать через Android `apksigner`.
Закрытый ключ и пароль не хранятся в репозитории. Для дальнейших обновлений
используйте исходный ключ `skystrike` и увеличивайте `versionCode`.

GitHub Actions: `.github/workflows/build-game.yml`. Workflow собирает ресурсы,
прогоняет тесты и Android Lint, проверяет запуск на эмуляторе, публикует
неподписанный APK и отчёты. Готовый подписанный APK передаётся отдельно.

## Структура

- `web/sim.js` — полёт, бой, радар, задания и ИИ.
- `web/world.js` — Three.js, модели, ландшафты и визуальные эффекты.
- `web/game.js`, `index.html`, `style.css` — интерфейс, ввод и сохранение.
- `web/audio.js`, `tools/make_audio.py` — звук и встроенные голосовые записи.
- `app/` — Android-оболочка и инструментальная проверка.
- `test/sim.test.js` — тесты игровой логики.

Модели и ландшафты создаются кодом проекта. Three.js распространяется по MIT;
его лицензия включена в APK. Голосовые файлы генерируются eSpeak NG.
