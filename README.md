# Bless Offban

Небольшое нативное Android-приложение для подготовки команд:
```text
/offban Ник 0 Причина
```

## Как пользоваться
1. Нажмите «+ Добавить ники».
2. Введите общую причину блокировки.
3. Вводите ники по одному и нажимайте «Добавить ещё».
4. Нажмите «Готово». Если поле заполнено, последний ник тоже попадёт в список.
5. Нажмите «Копировать» на нужной карточке. Команда попадёт в буфер обмена,
   карточка исчезнет, а следующие строки поднимутся вверх с новой нумерацией.

После копирования сохраняется оставшийся список: удалённые строки не вернутся
при следующем запуске. Если копирование не удалось, карточка остаётся в списке.

Готовые команды и незавершённый ввод сохраняются на телефоне.
Для новой причины добавьте следующую группу кнопкой «+».
Повторные ники внутри одной группы и пустые значения отклоняются.
Приложение работает без интернета и не запрашивает сетевые разрешения.
Для очистки списка предусмотрено подтверждение.

## Сборка и проверки
Конфигурация: Android 8.0+, compile/target SDK 36, JDK 17, Gradle 8.11.1, AGP 8.10.1.

В GitHub Actions откройте **Build APK**. После успешного запуска скачайте
артефакт **Bless-Offban-1.1** и извлеките файл `Bless-Offban-1.1.apk` из ZIP.

Локальная сборка:
```sh
gradle :app:assembleDebug :app:lintDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

С подключённым устройством или эмулятором:
```sh
gradle :app:connectedDebugAndroidTest
```
Инструментальные проверки проходят через реальный интерфейс: несколько ников,
последний ник при «Готово», разные причины, точное содержимое буфера обмена,
удаление скопированной строки, порядок и нумерация оставшихся строк,
восстановление черновика и оставшегося списка, копирование последней строки,
пустые значения и повторный ник.

Первая сборка использует автоматически создаваемую debug-подпись для установки
и проверки на телефоне. Перед регулярными обновлениями настройте постоянный
ключ подписи через секреты сборки; новый временный runner может создать другой
debug-ключ. Ключи и пароли не следует добавлять в репозиторий.
